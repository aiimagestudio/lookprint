# Lookprint 设计说明

把一批已经用肉眼选稳的 LoRA 训练集当成**金标准**，把每张图压成一组可解释的摄影指标，集合的均值/协方差就是这套「look」的指纹。新图的马氏距离越近，就越像金标准那套风格。金标准是什么风格都可以——本仓库最初的案例是一个反转片光色 + 强光影的数据集，下文的部分措辞沿用了那个案例。

## 指标在测什么

| 观感维度（以反转片案例为例） | 指标 |
|---|---|
| 反转片浓郁色彩 | HSV 饱和、Lab 色度、Hasler colorfulness |
| 暖高光 / 深阴影 | 高光与阴影各自的 Lab a* b*（split tone） |
| 强光影、明暗交界 | std(Y)、局部对比（去低频后的 std）、直方图双峰性、阴影占比 |
| 胶片高光滚降 | Y>0.98 像素比例（死白应很少） |
| 通道谁沉在暗部 | RGB 色阶、R−B 暖度 |
| 硬光方向 | 梯度、结构张量各向异性 |
| 颗粒 | 双边滤波后的高频残差 |

指纹建在「每张图的统计量」上，而不是把全部像素平均成一条直方图——明暗分离会被平均冲掉。

## 离群筛选

金标准内部也会有尾巴。默认用马氏距离的 90 分位当阈值。距离大不等于该删：大面积蓝天/沙漠/雪地常常是布光变体，对 LoRA 泛化有用。真正该复核的是调色家族已经离开这批的图。

剔除是**逻辑标记**：写入 `decisions.json`（`keep` / `maybe` / `drop`），金标准目录里的文件保持原样。清理后的训练集用「导出剩余」复制出来——全部金标准图去掉 `drop`（`keep`、`maybe`、未标都留下）。也可以单独导出已剔除的图做复核。导出是 `copy`，不能写回金标准目录。导出时同名 caption（`同stem.txt`）跟随图片一起复制，重名改名时 caption 同步改名。

## 候选扫描

对任意文件夹逐张提同样的向量，用金标准的 scaler + 协方差打分。≤ p90 标成「符合」，其余「需复核」。标记后的路径存在项目数据里，可复制到新目录当下一轮训练集。

## 刻意不做

- 不自动删除或移动金标准里的文件
- 不把标注写成图片旁边的 sidecar（避免污染数据集）
- 启动不强制选文件夹；默认打开已分析的金标准，选文件夹是功能按钮
- 第一版不用 CLIP/DINOv2。光色指纹对调色/光影类风格已经对症；语义层可以后加

## 项目数据

`data/projects/<id>/`

- `project.json` 金标准路径与分位
- `fingerprint.json` / `fingerprint.pkl`
- `metrics.csv`
- `plots/`
- `decisions.json` 离群筛选决定
- `marked_candidates.json` 扫描标记
- `scans/` 历次扫描
